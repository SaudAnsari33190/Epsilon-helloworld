# Epsilon Club | IIT Bhilai

Live Demo: https://saudansari33190.github.io/Epsilon-helloworld/

## About the Project
This website was built for HelloWorld, the 24-hour online hackathon hosted by OpenLake. 

It serves as an introductory landing page for Epsilon Club, the official robotics and hardware fabrication club at IIT Bhilai. The page is designed to introduce newcomers to what Epsilon builds, why it exists, and how to get involved.

## How to Run Locally
This project uses plain HTML and custom CSS, so there are no build steps or dependencies to install.

1. Clone this repository:
   git clone https://github.com/saudansari33190/Epsilon-helloworld.git

2. Navigate into the project folder:
   cd Epsilon-helloworld

3. Open index.html directly in any modern web browser.
