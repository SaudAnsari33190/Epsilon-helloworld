## About the Project
This project was built for HelloWorld, the 24-hour online hackathon hosted by OpenLake. 

It is an introductory website for Epsilon Club, the official robotics and hardware fabrication club at IIT Bhilai. The goal of this site is to take a first-year student with zero context and explain exactly what Epsilon builds (embedded systems, walking robots, motor drivers), why it matters, and how to get involved.
